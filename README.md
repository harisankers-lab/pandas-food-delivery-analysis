# QuickBite Food Delivery Data Analysis

A Python-based data analysis project using Pandas to clean, process and analyse food delivery order data across four cities.

### Analysis & Features
- Load and inspect order and restaurant datasets.
- Handle missing values, duplicates and inconsistent data.
- Clean delivery times and process date-time information.
- Merge order records with restaurant details.
- Analyse cancellation rates across cities.
- Calculate total revenue and average order value.
- Identify top-performing cuisines and restaurants.
- Compare citywise delivery performance and ratings.
- Analyse weekday activity and monthly revenue trends.
- Examine order sizes and repeat customer behaviour.
- Generate formatted reports and export cleaned data.

### Technologies
- Python 3
- Pandas
- NumPy
- Jupyter Notebook

### Concepts Practised
Data cleaning, preprocessing, missing value imputation, merging, grouping, aggregation, pivot tables, datetime operations, categorical analysis and data reporting.

### Project Structure
- `Harisanker_QuickBite_CaseStudy.ipynb` – Complete data analysis tasks and implementations.
- `quickbite_orders.csv` – Food delivery order dataset.
- `quickbite_restaurants.csv` – Restaurant information dataset.

### Run
Install the required libraries:

```bash
pip install pandas numpy jupyter
```

Open the notebook using Jupyter Notebook, JupyterLab or VS Code and execute the cells sequentially.

The two CSV files must remain in the same directory as the notebook.
